# Use of AI

I used ChatGPT extensively as a learning and programming assistant throughout the assignments. I used it to explain concepts, discuss implementation choices, help write and revise code, diagnose errors, design tests and experiments, and interpret results. I also used Cursor mainly for practical software-engineering support, such as debugging, resolving environment and dependency issues, navigating the codebase, and helping manage and upload the project to GitHub. I reviewed, adapted, ran, and tested the resulting code myself rather than treating AI-generated suggestions as automatically correct, and I used follow-up questions and experiments to make sure I understood the relevant implementations and concepts.

# Use of feedback

I did not submit any of the assignments for feedback, so I did not receive any formal feedback to incorporate.
